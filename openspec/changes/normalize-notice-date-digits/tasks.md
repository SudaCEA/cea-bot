- [ ] 1.2 单测（`tests/test_notice_parse.py`）：列表页给出 `２０２６－１０－０１`（全角数字 + 全角连字符）时，
      `published_on` **精确等于** `"2026-10-01"`。验证：用例在旧实现上失败、新实现上通过（红→绿）。
- [ ] 1.3 单测：其它 Unicode 十进制数字族（阿拉伯-印度 `٢٠٢٦-١٠-٠١`、天城文 `२०२६-१०-०१`）
      同样被归一化为 `2026-10-01`。验证：用例通过，且断言的是精确串而不是 `isascii()` 这类宽断言。
- [ ] 1.4 单测（负向，防"放宽过头"）：`2026-1-3`（未补零）、`二〇二六年十月一日`（中文数字）、
      `2026—10—01`（em dash）三种写法**都不算日期**（`published_on` 为空），
      且只出现既有的"缺少发布日期"告警、**没有**归一化告警。验证：用例通过。
- [ ] 1.5 单测（告警粒度）：一页 20 条里恰好 1 条被归一化时，归一化告警**恰好一条**且计数为 `1/20`；
      整页均为 ASCII 时**零条**归一化告警。验证：用例通过（同时钉住"不刷屏"与"不总是告警"两个方向）。
- [ ] 1.6 单测（把"理论上不可达"的分支变成可达断言）：直接对 `_normalize_date` 喂非 `Nd` 串
      （如 `"abcd-10-01"`）断言返回 `None`；并经 `_brief_of_row` 断言该条落成"缺少日期"、
      **不抛异常**（规格要求"SHALL NOT 因此中断本次运行"）。验证：用例通过。
- [ ] 1.7 注释与语义同步：`src/cea_bot/notices/models.py` 里 `published_on` 的"页面原文"改为
      "归一化后的 ASCII `YYYY-MM-DD`"；`parse.py` 的 `_DATE` 注释写明接受集与**已知边界**

      验证：`grep -rn "页面原文" src/` 无命中，且注释与 `specs/notice-digest/spec.md` 的新措辞一致。
